# 侧边栏新建空分类显示设计

## 问题

侧边栏创建分类后，分类顺序已写入 `categoryOrder`，但分类过滤逻辑只保留存在收藏记录的分类，导致没有收藏的刚创建分类不会显示；刷新后问题仍然存在。

## 设计

分类列表以两部分合并：

1. 优先保留 `categoryOrder` 中的显式分类，即使该分类当前没有收藏；这保证新建分类显示并保持其保存顺序。
2. 将收藏记录中发现、但不在 `categoryOrder` 中的分类按名称排序追加，兼容历史数据和外部写入。

分类树继续使用现有的路径构建逻辑，因此父子分类仍按 `a / b` 路径归入对应父组。创建分类时继续调用现有分类排序接口，刷新后从服务端恢复相同顺序。

## 验证

覆盖以下行为：显式空分类显示；显式分类顺序优先；未排序的收藏分类按名称追加；父子路径仍能构建分类树。

## 子分类创建入口

每个可写分类在侧栏悬停时提供“＋子分类”操作。点击后在该分类下方显示内联输入框，提交时将输入名称拼接为 `父级 / 子级`，调用现有分类排序接口保存，并立即在对应父组内显示。侧栏底部输入框继续用于创建顶层分类。
