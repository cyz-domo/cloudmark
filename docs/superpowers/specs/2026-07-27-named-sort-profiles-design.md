# 命名排序方案与首页展示配置

## 目标

让集合管理员创建、查看、编辑、删除多个命名排序方案，并在首页展示配置中同时选择展示分组和排序方案。所有设置由集合共享，访问者刷新或重新打开首页后仍使用相同配置。

## 用户行为

- 排序方案支持创建、列表查看、重命名、删除和维护书签顺序。
- 每个方案按分类保存书签 UUID 顺序；管理员在当前分组中使用拖拽调整顺序并保存到选中的方案。
- 首页展示配置同时包含展示组别和排序方案；排序方案可选固定默认排序或任意命名方案。
- 首页首次加载、刷新、解锁私有集合和保存设置后，同时应用首页组别与首页排序方案。
- 删除首页当前使用的排序方案时，首页排序回退为固定默认排序；删除普通方案不影响首页。
- 分组重命名同步更新首页组别；分组删除回退首页组别，并清理方案中已删除书签的顺序项。

## 数据与接口

- 新增 `sort_profiles` 表保存集合、名称和时间戳。
- 新增 `sort_profile_items` 表保存方案、分类、书签 UUID 与分类内顺序。
- `CollectionSettings` 新增 `homeSortProfile`，空字符串表示固定默认排序。
- 增加排序方案 CRUD API，以及按方案保存分类顺序的 API；全部要求 write token。
- 首页读取接口返回排序方案列表，默认排序不需要建表记录。
