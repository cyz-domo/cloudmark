# 分类拖拽排序与集合背景设计

## 目标

为收藏集合增加两项能力：按分类保存收藏顺序，以及通过图库 URL 设置集合页面背景。背景不上传图片，只保存外部链接。

## 分类拖拽排序

- 新增“自定义排序”模式。
- 进入该模式后提供分类快捷选择器，包括“全部”和当前集合已有分类。
- 选择分类后，仅允许拖动该分类中的收藏；“全部”按收藏所属分类分别维护顺序，不允许跨分类改变归属。
- 排序结果保存到 D1，刷新页面和其他设备访问同一集合时保持一致。
- 非自定义排序继续支持现有的最新、最早、标题、分类和 URL 排序。
- 已有数据通过迁移获得稳定的初始顺序，不删除或改写收藏内容。
- 只有具备 write token 的用户可以保存排序；无写权限时仍可查看自定义顺序。

## 集合背景 URL

- 在集合设置中增加背景图片 URL 输入项。
- 仅接受 `http`/`https` URL；链接保存到集合设置，页面直接加载外部图片。
- 不上传图片，不增加图片文件存储；输入 URL 长度限制为 5 MB 以内，并以页面安全样式显示。
- 背景设置由 write token 保护，并同步到其他设备。
- 清空 URL 后恢复默认页面背景。

## 数据与接口

- 新增 D1 migration，为收藏保存分类内排序值，为集合保存背景 URL。
- 集合读取接口返回背景设置和按默认顺序排列的收藏数据。
- 新增批量排序 API，仅接受当前集合中收藏的 UUID 顺序并验证 write token。
- 现有收藏增删改、迁移和导入流程保持兼容。

## 验证

- 运行 TypeScript 检查和生产构建。
- 使用本地 Cloudflare 预览验证背景设置、分类快捷切换、拖拽保存和刷新后顺序保持。
- 添加少量本地测试收藏，仅用于演示，不写入远程数据库。
